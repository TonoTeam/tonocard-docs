# 通过 AI Agent 使用 TonoCard 打电话

[English](agent-calling.md) · [产品介绍](../README.zh-CN.md)

TonoCard AI电话秘书卡通过蓝牙硬件、配套 App 和云端处理，将手机通话接入 AI。支持的调用流程可以让 Mac 或 PC 上的 AI 工具，通过机主的手机协助完成电话任务。

产品公开示例包括 **Workbuddy、Codex**，以及预约、餐厅订位、家政预约、售后报修、商务邀约等场景。这些示例不表示所有 AI 客户端及其所有版本都已兼容。

## 从哪里开始

1. 在 [TonoCard 官网](https://www.tonocard.com/)了解 Agent 打电话场景。支持的接入方案所需安装包与客户端说明由 TonoCard 另行提供。
2. 完成 TonoCard 硬件与手机 App 的设置，核对手机兼容条件，并保持必要的蓝牙和网络连接。
3. 按支持的接入方案所提供的现行说明完成安装与授权。
4. 向 AI 工具交代具体联系对象和通话目标，按界面流程确认。
5. 查看电话实际完成了什么，以及有哪些信息还需要自己决定。

客户端配置和授权步骤请按当前安装包随附的说明完成。本页提供产品公开展示流程的概览。

## 如何交代通话目标

有效的请求应说明联系谁、想办什么事、需要告知对方哪些事实，以及希望得到什么结果。例如：

> 拨打我提供的餐厅号码，询问今晚 7 点有没有四人桌。先告诉我可选时间，再确认是否预订。

这是请求示例，不是已完成电话的案例记录。具体操作与确认步骤取决于支持的接入方案及 App 版本。

## 通话仍由原手机承载

TonoCard 使用蓝牙连接和 App，让 AI 参与原手机的通话；机主无需开通运营商呼叫转移，也无需更换手机号。硬件、手机、App、服务及对应会员权益仍然是使用条件。
